What is ReproCrowd?

Many researchers already reproduce the numbers of a paper in their field — but unsystematically, on their own machine, with the results never leaving their laptop. ReproCrowd makes that systematic.

What a ReproCrowd certificate claims. It certifies that a paper's computation is reproducible and executable — a numerical/computational outcome, not a robustness test. It never rules on whether the science is correct, and it never fills the robustness outcome field.

The prompt

Tell your coding agent (Claude, Codex, DeepSeek, …) to certify the computational reproducibility of a paper. The agent needs nothing else — the rule pack is referenced by the prompt and pinned in the report.

ReproCrowd certification prompt 
ReproCrowd certification for `10.XXXX/YYYY`.

Certify the computational reproducibility of this paper: run its shipped code and data as a
Reproduction Study (same methodology, same tools) and record faithfully what reproduces and
what does not. Follow the ReproCrowd rule pack (https://forrt.org/crowd-repro, version pinned
in the report). Produce the artefacts per WORKFLOW.md into a new directory `-certification`.

Certify that the computation is reproducible and executable. Do NOT rule on whether the
scientific conclusion is correct. Use the FORRT nanopublication chain vocabulary. Report the
engine, model + provider, rules version, and environment you used.

How to use it

  1. Copy the prompt. Replace 10.XXXX/YYYY with the paper's DOI.
  2. Feed it to your LLM. Paste it into the coding agent you already use, in a fresh directory.
  3. Run it. The agent reads the rule pack, builds the reproducible pipeline, and certifies the computation.
  4. Submit. The agent writes certificate.json, certificate.md, SIGN-OFF.md and flora-entry.json and opens a pull request.
  5. Get signed. A human reviews the single SIGN-OFF.md, verifies the artifacts, and approves it for FLoRA.

Reports are comparable because the rule pack version, engine, model and provider are all recorded in the report. See the rule pack v1.0.0.
